2. WHAT IS INSIDE
==================================================

Autonom_Portfolio/
  The same document in three languages. It describes:
  - Team services (development, AI, design, DevOps, SEO)
  - Team technologies (languages, frameworks, databases, tools)
  - Firmware and microcontrollers (offline direction)
  - How we work, working conditions, edits and deadlines
  - Current services and prices
  - Contacts

Progects/Site.html
  Open it in any browser to see an example of a website made
  as one HTML file (HTML + CSS + JavaScript together).

Progects/exe.py
  Example of a Windows desktop program. The portfolio text is
  stored inside the script and shown in a scrollable window.


==================================================
3. HOW TO USE
==================================================

View the portfolio:
  Open any file from Autonom_Portfolio/ in a text editor.

Open the website example:
  Double-click Progects/Site.html.

Run the Windows program example:
  1. Install Python 3 (tkinter is included on Windows).
  2. Run:  py Progects/exe.py

Build a .exe file:
  1. Install auto-py-to-exe:  pip install auto-py-to-exe
  2. Run:  py -m auto_py_to_exe
  3. Select Progects/exe.py, choose "One File" and
     "Window Based", then convert.
