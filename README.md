HOW TO USE

View the portfolio:
Open any file from Autonom_Portfolio/ in a text editor.

Open the website example:
Double-click Progects/Site.html.

Run the Windows program example:

  Install Python 3 (tkinter is included on Windows).
  Run: py Progects/exe.py

Build a .exe file:

  Install auto-py-to-exe: pip install auto-py-to-exe
  Run: py -m auto_py_to_exe
  Select Progects/exe.py, choose "One File" and "Window Based",
  then convert.

View a presentation example:
Any HTML presentation we deliver is a single .html file —
double-click to open in a browser, works offline, adaptive
for phone, tablet and projector.
